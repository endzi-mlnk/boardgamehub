# BoardGameHub · Лабораторна робота №12

Відкрий `index.html` подвійним кліком. Сторінка, стилі й сценарії вже в цьому файлі. Фільтр ігор і навчальна форма працюють локально. Посилання в FAQ ведуть до чату й готують текст вибраного запитання. Форма перевіряє введені дані в браузері. Для справжнього листування підключи віджет чату за кроками нижче.

## 1. Опублікуй сайт через GitHub Pages

1. У GitHub створи публічний репозиторій `boardgamehub` і увімкни **Add a README file**, щоб одразу створити гілку `main`.
2. Відкрий **Add file → Upload files**. Завантаж готовий `index.html` у корінь репозиторію й натисни **Commit changes**.
3. Відкрий **Settings → Pages**. У **Source** вибери **Deploy from a branch**, укажи `main` і `/(root)`, натисни **Save**.
4. Після публікації натисни **Visit site** у **Settings → Pages**. Скопіюй повну HTTPS-адресу відкритої сторінки.

[Документація GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## 2. Підключи SendPulse Live Chat «Ботік»

1. У SendPulse відкрий **Chatbots → Manage bots → Add bot** (**Bot hinzufügen**) і вибери **Live chat**. Якщо «Ботік» уже створений для цієї адреси, відкрий його налаштування й перейди до **Website integration**.
2. Вибери встановлення віджета **на сторонньому сайті**. Встав опубліковану адресу з GitHub Pages, назви проєкт «Ботік» і налаштуй вигляд віджета.
3. Скопіюй весь код встановлення, який видасть SendPulse. У GitHub відкрий `index.html` і натисни олівець. Знайди коментар `SENDPULSE LIVE CHAT` наприкінці файлу та заміни весь коментар скопійованим кодом. Код має стояти перед `</body>`. У відкривальний тег `<script>` віджета додай два атрибути: `data-is-embedded="true"` і `data-embedding-target="#botik-chat"`. Збережи інші атрибути скопійованого коду. Натисни **Commit changes**.
4. Дочекайся оновлення GitHub Pages і натисни **Check installation** у SendPulse. Якщо ввімкнено список дозволених доменів, додай адресу сайту до цього списку.
5. Відкрий опублікований сайт, натисни **Написати Ботіку**. Сторінка прокрутиться до вбудованого чату. Напиши тестове повідомлення. Перевір, чи воно з’явилося в кабінеті SendPulse.

[Документація SendPulse Live Chat](https://sendpulse.com/knowledge-base/chatbot/livechat/set-up-code)

[Документація про вбудований режим](https://web.sendpulse.com/knowledge-base/chatbot/livechat/customize-with-js)


## 3. Перевір FAQ у чаті

Натисни запитання про наявність, доставку або правила. Сайт прокрутиться до чату й покаже текст запитання. Якщо браузер дозволив копіювання, просто встав текст у чат. Інакше скопіюй його з поля над чатом. Натисни кнопку надсилання у віджеті.

Для автоматичних відповідей налаштуй у SendPulse сценарії для цих трьох запитань і перевір кожне на опублікованій сторінці.
